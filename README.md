## About

Research engineer working on **large language model inference and serving systems**.
My work focuses on making large open-weight models run efficiently on heterogeneous
hardware, from single-GPU consumer setups to multi-node accelerator clusters — and on
turning those results into reproducible, production-grade serving systems.

## Research & Engineering Interests

- **LLM inference and serving** — KV cache management and compression, speculative
  decoding, long-context serving (up to 1M tokens), throughput and latency optimization
- **Mixture-of-Experts deployment** — expert parallelism, weight offloading to host
  memory and disk, quantization (FP8 / NVFP4) and its accuracy–latency trade-offs
- **Heterogeneous acceleration** — GPU and Ascend NPU deployment, cross-framework
  tuning and benchmarking, memory budget engineering for constrained devices
- **Model-serving platforms** — multi-model scheduling, accelerator resource pooling,
  and reliability engineering for production inference services
- **Knowledge editing and parametric memory** — editing and serving of lookup-based
  memory modules in sparse language models
